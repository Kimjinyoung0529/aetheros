디자인 방향 3개 모회사 AETHERION

디자인 방향 3개

시각 콘셉트만. 실제 커널·이미지는 아직 없습니다.

Concept A

유리알 · Glass Pearl

Liquid Glass 프로스티드 패널, 숨 쉬는 앰비언트 글로우, 바이올렛↔시안 하이라이트. 크롬은 얇고 여백은 넉넉. 프리미엄이지만 가벼운 인상.

Concept B

압축핵 · Compact Nucleus

저사양 폰을 위한 고밀도 타일·제스처 셸. 정보 밀도를 올리되 터치 타깃은 유지. “작아진 루트파일시스템”을 UI 메타포로 — 중첩 사각형, 압축된 아이콘 그리드.

Concept C

한빛 탭 · Hanbit

한국어 타이포그래피 우선, 밝은 소프트 악센트(가족 DNA) + 바이올렛 시스템 색. 태블릿 듀얼 페인·스플릿 앱을 기본으로. “예쁘고 읽기 쉬운” 쪽이 핵심.

쓸 기술 후보 (정직 나열)

출시 스택이 아니라, 디자인·프로토타입에 맞춰 검토할 후보예요.

베이스 · 압축

  • Alpine / musl 또는 Buildroot 루트fs
  • zstd · SquashFS 이미지
  • busybox / toybox 최소화 유틸
  • 참고 방향: postmarketOS식 mainline 경로

셸 · UI

  • Flutter / Dart — 폰·탭 단일 코드베이스
  • (먼 목표) Wayland + Smithay(Rust) 컴포지터
  • Skia / Impeller · Vulkan 가능 시
  • 제스처 셸 · 스플릿 페인 태블릿 레이아웃

커널 · AI · 빌드

  • 가까운 경로: Linux mainline
  • (연구) 마이크로커널은 훨씬 먼 목표
  • 온디바이스 사이드카: llama.cpp (가족 DNA)
  • CI: GitHub Actions + QEMU 이미지 빌드
